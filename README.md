# Blink Counter 👁️

A beginner-friendly Python project that uses your webcam to detect eye blinks and count them in real time.

## Features

- Uses webcam
- Detects face landmarks
- Detects eye closing/opening
- Counts blinks
- Press `Q` to exit

## Requirements

- Python 3.9 - 3.12 recommended
- Webcam
- VS Code or another Python IDE

## Installation

Open the project folder in VS Code and open the terminal.

Run:

```bash
python -m pip install -r requirements.txt
```

Then run:

```bash
python blink_counter.py
```

Allow camera access if Windows asks for permission.

## How to use

1. Look at the webcam.
2. Blink normally.
3. The counter will increase.
4. Press `Q` to close the webcam window.
